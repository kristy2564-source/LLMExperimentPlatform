# LLMExperimentPlatform

An open-source AI-assisted learning platform for supporting and assessing students’ Complex Problem-Solving (CPS) abilities through human-AI collaborative learning.

## Overview

LLMExperimentPlatform is an educational AI platform designed for middle and high school students to engage in authentic complex problem-solving tasks with large language model support.

Unlike traditional AI tutoring systems that directly provide answers, this platform emphasizes:

* Socratic-style AI scaffolding
* human-AI collaborative learning
* process-oriented assessment
* metacognitive reflection
* behavioral trace analysis

The system enables educators and researchers to observe how students:

* identify problems
* analyze information
* develop strategies
* collaborate with AI
* reflect on their learning process
* iteratively improve solutions

The current experimental learning scenario focuses on:

> Designing an intelligent classroom ventilation and energy-saving system.

Students complete a multi-step CPS workflow involving environmental analysis, strategy comparison, prompt engineering, emergency response planning, and reflective evaluation.

---

# Key Features

## Human-AI Collaborative Learning

The AI does not directly solve problems for students.

Instead, it acts as:

* a Socratic mentor
* reflective partner
* strategic guide
* metacognitive scaffold

The system encourages students to:

* think critically
* evaluate AI suggestions
* iteratively refine ideas
* develop independent reasoning abilities

---

## Multi-Step CPS Learning Workflow

The platform organizes learning into structured CPS stages:

1. Context introduction
2. Problem analysis
3. Strategy comparison
4. Prompt engineering
5. Emergency response design
6. Solution integration
7. Reflective evaluation

This workflow supports progressive cognitive scaffolding for complex problem-solving.

---

## Process-Oriented Assessment

Instead of evaluating only final answers, the platform records:

* dialogue interactions
* behavioral traces
* help-seeking behaviors
* revision history
* interaction timing
* reflective responses

This enables deeper analysis of:

* self-regulated learning
* metacognitive processes
* AI collaboration patterns
* CPS behavioral sequences

---

## Teacher Analytics Dashboard

The platform includes tools for teachers and researchers to monitor:

* student progress
* interaction frequency
* help usage
* dialogue history
* behavioral indicators
* CPS ability development

---

## Prompt Engineering Learning Support

Students learn how to:

* design AI prompts
* evaluate prompt quality
* iteratively optimize prompts
* understand human-AI interaction principles

The platform includes prompt testing and feedback mechanisms.

---

# Educational Design Principles

The project is grounded in:

* Complex Problem-Solving (CPS)
* Self-Regulated Learning (SRL)
* Socratic Scaffolding
* Project-Based Learning (PBL)
* Metacognitive Reflection
* Human-AI Collaborative Learning

Core design philosophy:

> AI should support human thinking, not replace it.

# Installation

```bash
git clone https://github.com/kristy2564-source/LLMExperimentPlatform.git
cd LLMExperimentPlatform
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Backend setup:

```bash
npm run server
```

Configure environment variables:

```env
MONGODB_URI=your_mongodb_uri
DEEPSEEK_API_KEY=your_api_key
```
